# مركز العناية — متجر إلكتروني

موقع متجر إلكتروني كامل (HTML + CSS + JavaScript فقط، بدون قاعدة بيانات
وبدون سيرفر) مع **لوحة تحكم مدمجة** لإضافة/تعديل/حذف المنتجات بسهولة من
المتصفح مباشرة، وكل تغيير بيتحفظ تلقائياً كـ commit على GitHub. إتمام
الطلب بيتم بالكامل عبر واتساب.

## 1. النشر على GitHub Pages (خطوة تُعمل مرة واحدة)

1. اعملي مستودع (Repository) على GitHub وارفعي عليه كل ملفات المشروع.
2. من **Settings → Pages** اختاري النشر من الـ branch الرئيسي (`main`)
   والمجلد `/root`.
3. افتحي `js/main.js` وعدّلي القيم دي في الأعلى:

   ```js
   const WHATSAPP_NUMBER = "201556954308";       // رقم واتساب المتجر
   const GITHUB_OWNER = "YOUR_GITHUB_USERNAME";   // اسم المستخدم بتاعك على GitHub
   const GITHUB_REPO = "YOUR_REPO_NAME";          // اسم المستودع بالظبط
   const GITHUB_BRANCH = "main";                  // أو "master" لو ده اسم الفرع
   ```

4. اعملي `commit` و `push`. الموقع هيبقى شغّال على الرابط اللي GitHub Pages
   بيديهولك، وهيكتشف المنتجات لوحده من أسماء الصور في المجلدات.

## 2. تفعيل لوحة التحكم (إضافة/تعديل/حذف من المتصفح)

عشان الموقع يقدر يحفظ تعديلاتك مباشرة على GitHub، محتاجة **مفتاح دخول
(Personal Access Token)** بصلاحية الكتابة على المستودع بتاعك. اعمليه مرة
واحدة كالتالي:

1. سجّلي دخول في GitHub، وروحي على:
   `Settings` (بروفايلك) → `Developer settings` → `Personal access tokens`
   → **`Fine-grained tokens`** → **`Generate new token`**.
2. اختاري:
   - **Repository access**: `Only select repositories` ← اختاري المستودع
     بتاع المتجر فقط (عشان المفتاح ميكونش له صلاحية على أي حاجة تانية).
   - **Permissions** → **Repository permissions** → **Contents** →
     اختاري **`Read and write`**.
   - **Expiration**: اختاري مدة مناسبة (مثلاً 90 يوم)، وجدّديه لما ينتهي.
3. دوسي **Generate token**، وانسخي المفتاح فوراً (GitHub بيوريهولك مرة
   واحدة بس).
4. في الموقع، دوسي على الزر الدائري (⚙) تحت يمين الشاشة → الصقي المفتاح
   → دخول.

### ملاحظات أمان مهمة

- المفتاح ده زي كلمة السر بالظبط — متشاركيهوش مع حد، ومتحطيهوش في أي
  مكان عام.
- استخدمي **Fine-grained token** مقتصر على هذا المستودع فقط (زي الخطوات
  فوق)، مش توكن عام له صلاحية على كل حساباتك.
- المتصفح بيحفظ المفتاح في جهازك بس (لن يتم رفعه على GitHub أبداً)،
  فلو استخدمتي جهاز مشترك أو عام، اعملي **"خروج"** من لوحة التحكم بعد
  ما تخلّصي.
- لو حسيتي إن المفتاح اتسرب، روحي على GitHub وامسحيه (Revoke) فوراً
  واعملي واحد جديد.

## 3. إزاي تضيفي/تعدّلي/تمسحي منتج (بعد تسجيل الدخول)

- **إضافة**: من لوحة التحكم، اختاري القسم والقسم الفرعي، اكتبي اسم
  المنتج والسعر، ارفعي الصورة، ودوسي "نشر المنتج". هيتحفظ على GitHub
  خلال ثوانٍ ويظهر في الموقع تلقائياً.
- **تعديل**: دوسي على أيقونة ✎ سواء من كارت المنتج نفسه أو من قائمة
  "المنتجات الحالية" في لوحة التحكم، عدّلي أي حقل (حتى الصورة اختياري
  تغييرها)، ودوسي "حفظ التعديلات".
- **حذف**: دوسي على أيقونة ✕ وأكّدي الحذف.

مفيش داعي تفتحي GitHub نفسه أو تتعاملي مع أي كود — كل حاجة من واجهة
الموقع.

## 4. التجربة على جهازك قبل الرفع (اختياري)

```bash
python3 -m http.server 8080
```

وافتحي `http://localhost:8080`. لو `GITHUB_OWNER`/`GITHUB_REPO` لسه متظبطش،
الموقع هيستخدم تلقائياً ملف `products.json` كنسخة تجريبية بس. لوحة التحكم
مش هتشتغل قبل ما يبقى الموقع فعلاً على GitHub بمفتاح صحيح.

## 5. الفئات والفئات الفرعية

الأسماء العربية للفئات موجودة في أول ملف `js/main.js`
(`CATEGORY_LABELS`, `SUBCATEGORY_LABELS`, `CATEGORY_SUBCATEGORIES`) —
لو ضفتي مجلد فرعي جديد، ضيفيه في التلات أماكن دول.

## 6. المميزات المتوفرة حالياً

- اكتشاف المنتجات تلقائياً من أسماء الصور في المستودع — من غير أي بناء
  يدوي (build step).
- **لوحة تحكم كاملة**: إضافة / تعديل / حذف منتجات مباشرة من المتصفح،
  بتحفظ كـ commits حقيقية على GitHub.
- عرض المنتجات مقسمة حسب الفئة، مع شريط فئات قابل للتمرير.
- شريط بحث فوري بالاسم، وترتيب حسب السعر أو الاسم.
- سلة تسوق مع التحكم في الكمية، ومحفوظة تلقائياً في `localStorage`.
- نموذج لجمع بيانات التوصيل (الاسم، الهاتف، العنوان) قبل إرسال الطلب.
- زر "إتمام الطلب عبر واتساب" ببناء رسالة جاهزة فيها كل التفاصيل.
- تصميم متجاوب يشتغل كويس على الموبايل.

## 7. هيكل الملفات

```
├── css/style.css              التنسيق العام (يشمل تصميم لوحة التحكم)
├── js/main.js                 كل منطق الموقع (اكتشاف المنتجات، لوحة التحكم، سلة، واتساب)
├── img/logo.png                شعار الموقع
├── img/hero-photo.jpg           صورة الغلاف الرئيسية
├── products.json                نسخة احتياطية للتجربة المحلية فقط
├── scripts/
│   ├── generate-products.js     أداة اختيارية للتجربة المحلية فقط
│   └── make_placeholders.py     (اختياري) صور تجريبية للعرض فقط
├── 1_skincare/ ... 7_offers/     مجلدات الفئات وصور المنتجات
└── index.html                   الصفحة الرئيسية
```

## 8. حدود الحل الحالي (بصراحة)

- لوحة التحكم بتحتاج اتصال إنترنت وGitHub Token صالح — مفيش تعديل
  "أوفلاين".
- GitHub بيحدد أقصى 5000 طلب/الساعة للمستخدمين المسجّلين بمفتاح (أعلى
  بكتير من احتياج متجر صغير أو متوسط).
- كل تعديل بيعمل commit جديد في تاريخ المستودع — ده طبيعي وغير ضار،
  بس يعني تاريخ الـ commits هيبقى فيه كل عمليات الإضافة/الحذف.
